# Book Catalogue

Програмний застосунок для керування каталогом книг, розроблений мовою Java з використанням JavaFX.

## Можливості

- Додавання книг
- Видалення книг
- Оновлення книг
- Пошук книг
- Збереження каталогу у файл
- Завантаження каталогу з файлу

## Технології

- Java 21
- JavaFX
- Maven
- IntelliJ IDEA

## Запуск

1. Відкрити проєкт в IntelliJ IDEA.
2. Дочекатися завантаження залежностей Maven.
3. Запустити команду `javafx:run`.
